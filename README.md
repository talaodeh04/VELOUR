# VELOUR

### Luxury Beauty & Fashion E-Commerce

VELOUR is a modern luxury e-commerce website designed for a boutique brand offering curated beauty products, accessories, and handbags.

The project focuses on combining a refined editorial aesthetic with a smooth and intuitive shopping experience. Its visual identity uses warm ivory tones, dusty rose, deep burgundy, and champagne-gold accents to create a sophisticated and premium atmosphere.

---

## ✨ Overview

VELOUR is designed as a complete boutique shopping experience where users can explore curated products, discover collections, view product details, manage their shopping cart, and complete the checkout flow.

The interface follows a consistent **quiet luxury** design direction with editorial photography, elegant typography, spacious layouts, subtle animations, and responsive components.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/talaodeh04/VELOUR.git
```

### 2. Navigate to the project

```bash
cd VELOUR
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will then be available through the local development URL provided by Vite.

---

## 📦 Production Build

To create a production build:

```bash
npm run build
```

To preview the production build locally:


## 🖼️ Image System

All website imagery is organized locally inside the `images` directory.

This keeps the visual identity consistent and avoids relying on random external image sources.

The image system is divided into:

```text
images/
├── hero/
├── categories/
├── about/
├── social/
├── editorial/
├── makeup/
├── accessories/
└── bags/
```

Product images use a consistent square composition, while editorial and hero imagery use dedicated aspect ratios for their respective sections.

## 🛒 Shopping Experience

The shopping flow is designed around a simple user journey:

```text
Discover
   ↓
Browse Collections
   ↓
Search / Filter
   ↓
View Product
   ↓
Add to Cart
   ↓
Review Cart
   ↓
Checkout
```

The interface keeps the shopping process visually clean while maintaining the premium identity of the brand.

---

## 📂 Product Data

Product information is maintained in:

```text
src/products.ts
```

The product catalog contains information such as:

* Product ID
* Product name
* Category
* Description
* Price
* Product image
* Additional product metadata

This structure makes it easy to update or expand the catalog without changing the main interface.
